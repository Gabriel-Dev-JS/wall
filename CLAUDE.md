# Projeto WALL

Controle de gastos offline.

## Objetivo

Aplicativo mobile para controle simples de receitas e despesas.

## Tecnologias

- Expo
- React Native
- TypeScript
- expo-sqlite

## Regras

- O aplicativo deve funcionar 100% offline.
- Não criar backend.
- Não utilizar Firebase.
- Não utilizar Supabase.
- Não utilizar APIs externas.
- Valores monetários devem ser armazenados em centavos.
- Código deve ser TypeScript.
- Separar lógica de negócio da interface.
- Evitar dependências desnecessárias.
- Priorizar simplicidade.
